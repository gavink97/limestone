== Getting Started
=== Installation
requirements:

```
docker
docker-compose
```

Ensure you have any docker images you need pulled (or built) before starting Limestone. For example:
```
docker pull traefik/whoami
```

== Caddyfile

=== Limestone Options
You can check `Caddyfile.example` for quickstart boilerplate

==== Docker Network
```
docker_network {docker_network}
```

Defines the docker network the members of the pool will join.

==== Default Pool
```
default_pool {pool_name}
```

Defines the default pool limestone will route to. *This is required.*

==== Default Pool Config
```
default_pool_config {
	backend_port 80
	health_path /
	min 1
	max 4
	target_inflight 2
	scale_out_cooldown 3s
	scale_in_cooldown 15s
	drain_grace 5s
}
```

Defines the default pool configuration for all pools. Pools will inherit these attributes if not defined.

==== Rules
```
rules {
	/api/abc {pool_name}
	/api/xyz {pool_name}
}
```

When using multiple pools you can define routing rules. Limestone will route to a pool based on the defined prefix.

==== Pool {pool_name}
```
pool {pool_name} {
	image {docker_image_name}
	backend_port 80
	health_path /
	min 1
	max 4
	target_inflight 2
	scale_out_cooldown 3s
	scale_in_cooldown 15s
	drain_grace 5s
}
```

Defines a pool limestone will create and route to. *A `pool_name` and `image` are required to define a pool.*

=== Route Requirements
*Ensure limestone is defined in your `route` and limestone_pool in `reverse_proxy`*

```
:8080 {
	route {
		limestone
		reverse_proxy {
			dynamic limestone_pool
			lb_try_duration 5s
		}
	}
```

== Testing

=== Developer Endpoints
Important note: The Admin API is exposed at `0.0.0.0:2019` for injection testing purposes. In a production environment it is best advised to revert to `localhost:2019` or use `admin off`.

==== GET /limestone/pools
Returns a list of available pools.

==== GET /limestone/members/{pool_name}
Returns a list of pool members.

==== POST /limestone/test/reconciler/{pool_name}
This endpoint is designed to test the conditions that cause the reconciler to scale up, scale down, and retire members.

```
{
	"id": "member_id"
	"condition": "unhealthy | healthy | draining | remove | inflight"
	"inflight_demand": >= 0
}
```

=== Injection Testing
`testing/main.go` serves as a small yet expandable automated injection testing suite for assurance.

`--inflight` flag enables testing inflight injections which expand and decrease pool size.

`--verbose` flag enables verbose info logging of pool members and their state during the injection test.
